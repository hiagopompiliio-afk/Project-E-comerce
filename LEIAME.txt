Phomps Shop - Projeto E-commerce 


Página da loja virtual fictícia Phomps Shop
(produtos de tecnologia). Desenvolvida com HTML5, CSS e JavaScript.

ESTRUTURA DE PASTAS
-------------------
projeto-ecommerce/
├── index.html          → Página principal (landing)
├── carrinho.html       → Página do carrinho
├── css/
│   └── style.css
├── js/
│   ├── script.js       → Menu, adicionar ao carrinho, frete, formulário
│   └── cart.js         → Lógica da página do carrinho
├── img/
│   ├── produto1.jpg … produto6.jpg
│   └── (coloque logo.png aqui se quiser logo em imagem)
└── LEIAME.txt


COMO ABRIR
----------
1. Extraia a pasta.
2. Abra index.html no navegador.
3. Clique em "Adicionar" nos produtos → o contador do 🛒 sobe.
4. Clique no 🛒 → abre carrinho.html com os itens salvos.


COMO ABRIR O PROJETO

1. Baixe ou clone o repositório.
2. Abra a pasta "projeto-ecommerce".
3. Clique duas vezes no arquivo "index.html"
   OU abra-o pelo navegador (Chrome, Firefox, Edge etc.).
4. Para testar a responsividade:
   - Pressione F12 (DevTools)
   - Ative o modo de dispositivo (ícone de celular/tablet)
   - Teste nas larguras: celular (~375px), tablet (~768px) e notebook (~1024px+)
